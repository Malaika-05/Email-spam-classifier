# Email-spam-classifier

📌 Overview

The Email Spam Classifier is a machine learning-based web application that automatically detects whether a given email or message is Spam or Not Spam (Ham).

It uses Natural Language Processing (NLP) techniques and a trained machine learning model to analyze text and make accurate predictions in real time.

This project demonstrates how machine learning can be applied to solve real-world problems in email filtering and cybersecurity.

# 🚀 Features

🔍 Classifies emails as Spam or Ham

🧠 Powered by a trained Machine Learning model

📊 Uses NLP techniques for text processing

🌐 Simple and interactive web interface

⚡ Fast and real-time predictions

💾 Lightweight and easy to deploy

# 🛠️ Tech Stack

Python

Flask (Backend web framework)

Scikit-learn (Machine Learning model)

Pandas & NumPy (Data processing)

NLTK / NLP techniques (Text preprocessing)

HTML, CSS (Frontend)

# How It Works

User enters an email or message in the input box.

Text is preprocessed (cleaning, tokenization, vectorization).

The trained ML model analyzes the input.

The system predicts:

📩 Ham (Not Spam)

🚫 Spam

Result is displayed instantly on the web interface.
